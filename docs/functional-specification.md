# Функциональное описание ПО

Веб-сервис предназначен для исследователей и студентов: собирает публикации, помогает извлекать сведения, сравнивать исследования и проверять основание ответа. Ниже зафиксировано планируемое поведение.

## Роли

| Роль | Действия |
|---|---|
| Исследователь | Собственные проекты, PDF, вопросы, сравнение, источники, экспорт |
| Администратор | Учётные записи, конфигурация моделей и API, ограничения, журналы ошибок |

Гость может зарегистрироваться и войти. Анализ выполняется после авторизации. Административная роль не предполагает автоматического доступа к содержимому всех проектов.

## Функции

| Код | Функция | Поведение |
|---|---|---|
| F01 | Регистрация и авторизация | Создание учётной записи, вход в личный кабинет и разграничение доступа к проектам. Администратор управляет учётными записями. |
| F02 | Управление проектами | Создание тематических проектов, хранение публикаций, результатов и истории анализа. |
| F03 | Загрузка публикаций | Добавление PDF, извлечение текста с сохранением номеров страниц. Отображение состояния обработки и понятных сообщений об ошибках. |
| F04 | Поиск научных работ | Поиск через научный API, просмотр названия, авторов, года и идентификаторов публикации. Добавление выбранных работ в проект с учётом доступности полного текста. |
| F05 | Вопросы по статьям | Ответы по одному или нескольким выбранным документам со ссылками на подтверждающие фрагменты. При недостатке сведений система сообщает об этом. |
| F06 | Сравнение публикаций | Таблица по полям «цель», «метод», «данные», «результаты», «ограничения». Создание собственных полей с инструкциями. Отсутствующие сведения отмечаются явно. |
| F07 | Проверка источников | Переход от утверждения в ответе или значения в таблице к документу, странице и исходному фрагменту. |
| F08 | Управление анализом | Просмотр плана, состояния задания и журнала действий агента. Остановка и повторный запуск обработки без потери сохранённых результатов. |
| F09 | Экспорт результатов | Выгрузка сравнительной таблицы в CSV с идентификаторами публикаций и ссылками на использованные источники. |
| F10 | Настройка сервиса | Администратор выбирает провайдера модели, настраивает внешние API и ограничения обработки, просматривает журналы ошибок. |

## Сквозные сценарии

1. Создать проект → загрузить PDF → дождаться обработки → задать вопрос → проверить страницу и фрагмент источника.
2. Выбрать несколько публикаций → задать поля и инструкции → проверить значения и отсутствующие сведения → экспортировать CSV.
3. Запустить многошаговый анализ → наблюдать состояние и журнал действий → остановить задание → повторить запуск с сохранением истории.

Для текста без достаточного подтверждения сервис сообщает о нехватке сведений. Полный набор критериев — в [паспорте](criteria-passport.md).
