# Задачи проекта

P0 — обязательная первая версия; P1 — развитие после её проверки. Коды сохранены для связи с доской. Исполнителей команда назначает отдельно.

## Первая версия

| Код | Задача | Критерий готовности | Зависит от | Статус |
|---|---|---|---|---|
| T01 | Обзор аналогов и критерии | Описаны функции и интерфейсы, есть определения критериев и ссылки на источники | — | Готово |
| T02 | Зафиксировать границы MVP | Для загрузки, вопроса и проверки источника записаны входы, результаты и ошибки | T01 | К выполнению |
| T03 | Контрольный корпус и методика | 10–15 доступных статей, 20 вопросов с эталонными фрагментами, включая отсутствие ответа; пороги заданы до итогового теста | T02 | К выполнению |
| T04 | Прототип интерфейса | Показан путь от загрузки до страницы источника, включая ожидание и ошибки | T02 | К выполнению |
| T05 | Данные и API | Описаны сущности, запросы, статусы заданий, авторизация и проверка доступа к проекту | T02, T03 | К выполнению |
| T06 | Скелет проекта и CI | Клиент и API запускаются по инструкции; сборка и проверка работоспособности проходят в CI | T05 | К выполнению |
| T07 | Обработка PDF | Текст и фрагменты сохраняют страницы; есть статусы, поиск повторной загрузки и понятные ошибки | T05, T06 | К выполнению |
| T09 | Вопросы и ответы с цитатами | Поиск находит фрагменты; ответ ссылается на них; нехватка сведений отмечается явно | T03, T07 | К выполнению |
| T12 | Связать интерфейс с API | Весь сценарий проходит в браузере; цитата открывает нужную страницу PDF | T04, T07, T09 | К выполнению |
| T13 | Проверка и демонстрация | Выполнен контрольный набор; сохранены результаты и ошибки; есть инструкция и демонстрация | T03, T12 | Запланировано |

## Дальнейшее развитие

| Код | Задача | Критерий готовности | Зависит от | Статус |
|---|---|---|---|---|
| T08 | Поиск через arXiv API | Поиск и импорт метаданных без дубликатов; обработаны ошибки и лимиты API | T02, T06 | Отложено |
| T10 | Сравнение и экспорт | Пользовательские поля, источники значений, отметки отсутствия данных и корректный CSV | T09, T12 | Отложено |
| T11 | Управляемый агент | Ограничение шагов, журнал вызовов инструментов, остановка и восстановление; качество сопоставлено с базовым режимом | T08, T09 | Отложено |

Готовность обязательной версии оценивается независимо от T08, T10 и T11. [Календарный план](PLAN.md) · [Описание ПО](docs/design.md)
